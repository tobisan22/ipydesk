# 実行とデバッグ

[← README に戻る](../README.md)

## 実行とセッション

F5 を押すと、ターミナル「IPyDesk」で IPython セッションが起動し、その中でスクリプトを実行します。
実行が終わるとプロンプト `In [n]:` に戻り、変数はそのまま残ります。

- **2 回目以降の F5** は、同じセッションで再実行します
- **実行中に F5** を押すと、別のセッションで実行します（複数のセッションを並行して動かせます）
- **Ctrl+Alt+F5** は、新しいセッションで実行します
- **Ctrl+Shift+F5**（New Session）は、空のセッションを 1 つ追加します。既存のセッションはそのままで、スクリプトは実行しません
- ステータスバーのセッション名をクリックすると（IPyDesk: Select Session）、F5 / セル実行の送り先にするセッションを切り替えられます

## 赤丸（ブレークポイント）

行番号の左をクリックして赤丸を置き、F5 を押すと、その行で止まります。

| キー | 停止中の動作 |
|---|---|
| **F5** | 続行 |
| **F10** | ステップオーバー |
| **F11** | ステップイン |
| **Shift+F11** | ステップアウト |
| **Shift+F5** | デバッガを抜けてプロンプトへ |

- 停止中は、Workspace ビューと Variable Editor に**そのフレームの変数**が表示されます
- 停止中に Ctrl+Shift+Enter を押すと、選択範囲を停止位置のフレームで実行します
- 赤丸は**フォルダを開いているとき**だけ効きます（ファイル単体で開くと効きません）

### 赤丸があると遅いとき

赤丸がある実行ではトレースが入るため、遅くなります（赤丸が無ければ通常と同じ速度です）。

- **Ctrl+F5**（IPyDesk: Run Without Breakpoints）: 赤丸を消さずに、無視して全速で実行します
- **IPyDesk: Toggle All Breakpoints**: すべての赤丸を一時的に無効にします。個々の赤丸の設定は変わりません
- ステータスバーの **BP** 表示をクリックすると（IPyDesk: Show Breakpoints）、有効な赤丸の一覧が出ます
- 実行が遅くなったときは通知が出て、「赤丸なしで再実行」などを選べます（秒数は `ipydesk.slowRunNotifySec`）
- `ipydesk.breakpointMode` を `inject` にすると、赤丸の行に到達するまで全速で実行します（試験的な方式です）

## セル実行

`# %%` の行でスクリプトを区切ると、Ctrl+Enter でカーソルのあるセルだけを実行できます。
セルの最後が式なら値が `Out[n]` に表示され、赤丸もそのまま効きます。

```python
# %% データの準備（1 回だけ）
import numpy as np
x = np.linspace(0, 10, 100)

# %% ここだけ何度も試す
y = np.sin(2 * x)
y.max()
```

| キー | 動作 |
|---|---|
| **Ctrl+Enter** | セルを実行 |
| **Shift+Enter** | セルを実行して次のセルへ |
| **Ctrl+Shift+Enter** | 選択範囲（選択が無ければ現在行）を実行 |

> Jupyter 拡張に Ctrl+Enter を取られる場合は、`Ctrl+Shift+P` →
> 「**IPyDesk: Use IPyDesk Cell Keys**」を実行してください。

## エラーが出たとき

エラーで止まらずにプロンプトへ戻り、ステータスバーに **⚠ エラー名（ファイル:行）** が出ます。
クリックすると、**エラーが起きた行で止まった状態**に入れます。重い計算の最後で落ちても、走り直す必要はありません。

最初からエラーの行で止めたいときは、**Alt+F5**（IPyDesk: Run (Stop on Error)）で実行します。

## キー操作の一覧

| キー | 動作 |
|---|---|
| **F5** | 実行（2 回目以降は同じセッションで再実行。実行中なら別のセッションで実行） |
| **Ctrl+F5** | 赤丸を無視して実行 |
| **Alt+F5** | 実行し、エラーが出たらその行で止まる |
| **Ctrl+Alt+F5** | 新しいセッションで実行 |
| **Ctrl+Shift+F5** | New Session: 空のセッションを 1 つ追加する |
| **Ctrl+Enter** / **Shift+Enter** | セルを実行 / 実行して次のセルへ |
| **Ctrl+Shift+Enter** | 選択範囲（選択が無ければ現在行）を実行。停止中は停止位置のフレームで実行 |
| **F5 / F10 / F11 / Shift+F11** | 停止中: 続行 / ステップオーバー / ステップイン / ステップアウト |
| **Shift+F5** | 停止中: デバッガを抜けてプロンプトへ |
| **Ctrl+C** | Figure タブ: 図を画像としてコピー |
| **F5**（エクスプローラー） | 選んでいる `.bat` / `.cmd` / `.exe` / `.ps1` をターミナルで実行（[詳しく](run-file.md)） |

キーの無いコマンドは、`Ctrl+Shift+P` で「IPyDesk」と入力すると一覧が出ます。

## 制約

- 停止中のマウスホバーでの変数表示には未対応です（Workspace ビューか `ipdb>` で確認します）
- 標準ライブラリ・IPython・matplotlib の内部には F11 でも入りません
