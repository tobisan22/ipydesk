# メモ（Notes ビュー）

[← README に戻る](../README.md)

アクティビティバーの IPyDesk に **NOTES** があり、セクションに分けてメモを書けます。
入力すると自動で保存され、**どのフォルダを開いても同じメモ**が出ます。

## セクションの操作

| 操作 | 方法 |
|---|---|
| 追加 | **＋ セクション** |
| 名前を変更 | 見出しをクリック（Enter で本文へ） |
| 折りたたみ | **▾ / ▸**（見出しのダブルクリックでも可）。**⇕** ですべて折りたたむ / 展開 |
| 並べ替え | **⋮⋮** をドラッグ（見出しにマウスを乗せると出ます）。キーボードでは **Alt+↑ / Alt+↓** |
| 本文をコピー | **⧉**（Shift+クリックで `## 見出し` も含めてコピー） |
| 削除 | **✕**（本文があるときは 2 回クリック） |

折りたたんだ状態も保存されます。

## コードをメモに切り抜く

エディタで選択して右クリック →「**IPyDesk: Add Selection to Notes**」で、選択範囲（選択が無ければ現在行）を
ファイル名・行番号・時刻つきで追記します。追記先は最後に入力したセクション（無ければ最後のセクション）です。

## 保存先（notes.md）

- 保存先は**ユーザー単位**です: `%APPDATA%\Code\User\globalStorage\bisan.ipydesk\notes.md`
- NOTES 右上のアイコン（IPyDesk: Open Notes File）で、`notes.md` をエディタで開けます
- `notes.md` は Markdown で、`## 名前` の行がセクションの区切りです（コードブロックの中の `##` は区切りになりません）
- VS Code を複数ウィンドウで開いていても、ほかのウィンドウで書いた内容が反映されます（同時に書いた場合は、後から保存した方が残ります）

## デフォルトのメモ

最初は、次のメモが折りたたんで入っています。

- IPyDesk のショートカット（キー操作・コマンド・停止中の ipdb コマンド）
- matplotlib: subplots の基本
- matplotlib: 軸の範囲・目盛り
- 外部 exe の実行（subprocess）

デフォルトのメモの扱いは次のとおりです。

- いらなければ、普通のセクションと同じように ✕ で消せます。消しても再び入ることはありません
- 拡張の更新でデフォルトのメモが増えたときは、増えた分だけが入ります
- NOTES 右上の「…」→「**IPyDesk: Restore Default Notes**」で、消したデフォルトのメモだけを末尾に戻せます（同じ名前のセクションがあれば戻しません）
