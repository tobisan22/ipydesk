## Workspace ビュー

アクティビティバーの IPyDesk に **WORKSPACE** があり、セッションの変数を一覧表示します。

- 実行・ステップのたびに最新の値へ更新されます
- ブレークポイントで停止中は、そのフレームの変数を表示します
- 配列・DataFrame・Series・list を**ダブルクリック**すると、Variable Editor で開きます

## Variable Editor

### 開く

- Workspace ビューで変数を**ダブルクリック**（右クリック →「IPyDesk: Open Variable…」、行の ⊞ でも可）
- `sim.state` や `d['k']` のような式は、「IPyDesk: Open Variable…」で入力して開けます

100 万行の配列でも、見えている範囲だけを読むので軽く動きます。実行・ステップのたびに最新の値へ更新されます。

### 範囲を選んでプロット

ドラッグ・Shift+クリック・行／列見出しのクリックで範囲を選び、**📈 Plot / X–Y / Scatter / Hist / Image** を押すと図が出ます。
何も選んでいなければ全体が対象です。

- 実行されるのは `plt.plot(x[2:7, 1:3])` のような 1 行のコードで、ターミナルの履歴に残ります（ボタンにマウスを乗せると事前に確認できます）
- 図は変数ごとに 1 枚（`plt.figure("x")`）に描き直します。前に描いた図はそのタブの上側に残るので、スクロールして見比べられます
- 列見出しを **Ctrl+クリック**すると、離れた列をまとめて選べます（もう一度で外す）
- **X–Y** は、いちばん左の列が X、残りが Y です（time・altitude・speed を選べば `plt.plot(x[:, 0], x[:, [3, 7]])`）
- **Subplots** をオンにすると、2 列以上を同じ軸に重ねずに、列ごとに段を分けて描きます（X 軸は共有）

| キー | 動作 |
|---|---|
| **Shift+Space** | 行全体を選ぶ |
| **Ctrl+Space** | 列全体を選ぶ |
| **Ctrl+C** | 選択範囲をコピー |

### コピーと統計

- **Ctrl+C**（または Copy）で、選択範囲をタブ区切りでコピーします。Excel にそのまま貼れます（数値は丸めずに出ます）
- 範囲を選ぶと、下に **n・min・max・mean・std(N−1)・NaN の数** を出します。数字をクリックすると、丸めない値をコピーします
- **Inspect** で、選んだセルの値を下のペインに全文で表示します（長い文字列・改行を含む文字列など）

### 見た目を変える

- 列見出しの境目をドラッグで**列幅**、行見出しの下端をドラッグで**行の高さ**を変えられます。境目のダブルクリックで内容に合わせます
- 高くした行は折り返して表示します（右クリックで「既定に戻す」など）
- ツールバーで行の高さ（詰める／標準／広く）、Ctrl+ホイールで**表示倍率**（50〜200%）を変えられます
- 列幅・行の高さの設定・倍率は、変数ごとに覚えます
- 見出しの右クリックで**ウィンドウ枠の固定**（ここまでの列・行を固定）ができます
- ツールバーの **Heat** で、値の大きさに応じた色分けができます

### 3 次元以上の配列

表の上の**次元バー**で、軸ごとに「行・列・固定」を選びます。

- 列の軸を 2 つ以上にすると、1 列に並べて展開します（`R.shape = (10001, 3, 3)` → 行 10001 × 列 9）
- 時系列らしい配列は、開いたときに自動で展開します
- 今の見え方は `R.reshape(10001, -1)` のような式で表示します。クリックすると `:, 500, :` のような添字で指定できます
- 固定した軸の番号は ◀▶・ホイール・**Alt+↑↓** で変え、**Alt+←→** で固定の軸を切り替えます

### DataFrame・xarray

- DataFrame の **MultiIndex** は、見出しを段に分けて表示します
- xarray の DataArray は、軸の名前と座標を見出しに使います

## Open Desk

「**IPyDesk: Open Desk**」（Workspace ビュー右上の ⊞ アイコン）で、MATLAB のデスクトップのように並べます。

```
┌──────────┬──────────────┬──────────────┐
│Workspace │ コード        │ Figure /      │
│          │              │ Variable Editor│
│          ├──────────────┴──────────────┤
│          │ IPyDesk コンソール              │
└──────────┴─────────────────────────────┘
```

- セッションが無ければ空のセッションを起動し、閉じていた Figure タブも開き直します
- Workspace を右側に置きたい場合は、ビューをセカンダリ サイド バーへドラッグしてください（VS Code が位置を覚えます）
